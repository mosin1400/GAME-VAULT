# برنامهٔ اجرایی بازسازی Game Vault

این برنامه، Backlog اصلی را به بسته‌های کوچک و قابل‌آزمایش تبدیل می‌کند. هر بسته فقط بعد از گذراندن آزمون‌های همان بسته وارد مرحلهٔ بعد می‌شود.

## قواعد اجرا

1. پیش از جابه‌جایی هر فایل، مسیرهای عمومی، API و صفحه‌های وابسته با تست محافظ ثبت می‌شوند.
2. `.env` هرگز خوانده یا در هیچ تست/لاگی چاپ نمی‌شود.
3. بازآرایی ساختاری نباید CSS نهایی، URLهای عمومی یا رفتار کاربر را تغییر دهد.
4. هر تغییر AI ابتدا Diff و Snapshot دارد و بدون تأیید کاربر روی فایل اعمال نمی‌شود.
5. هر بسته با بازکردن واقعی صفحه و آزمون ایستا/سرور تأیید می‌شود.

## بسته A — قرارداد و نقشهٔ پروژه

**هدف:** ساخت معیارهایی که مطمئن شویم بازآرایی رفتار برنامه را تغییر نداده است.

- [x] فهرست مسیرهای عمومی: داشبورد، مدیریت، پروفایل، جزئیات بازی، ورود، Studio و APIها.
- [x] تست پاسخ `/api/games`، فایل‌های بازی و دریافت متادیتا.
- [x] تست ساختار هر نسخه: `games/<slug>/versions/<version>/game.json` و `README.md`.
- ثبت رفتار ورود مدیر و محدودیت Studio عادی.
- [x] خروجی: قراردادهای تست در `tests/` و یک نقشهٔ وابستگی مختصر در `docs/`.

**معیار عبور:** همهٔ مسیرهای قدیمی پیش از هر جابه‌جایی پاسخ موفق بدهند.

## بسته B — بازآرایی بدون تغییر رفتار

**هدف:** شکستن فایل‌های بزرگ و یک‌خطی، بدون تغییر UI یا API.

- [ ] جداسازی `server.js` به routeهای بازی، فایل، متادیتا، حساب، AI و Theia.
- [x] استخراج ابزارهای مشترک: اعتبارسنجی مسیر، JSON، نشست، پاسخ HTTP و تاریخچهٔ Snapshot.
- شکستن JavaScript صفحه‌ها به ماژول‌های صفحه و shared utilities.
- تبدیل CSSهای فشرده به فایل‌های خوانا با tokenهای مشترک، بدون تغییر selector یا مقدار نهایی.
- حذف فقط فایل‌های تکراری یا کد مرده‌ای که با جست‌وجو و تست اثبات شده باشد.

**معیار عبور:** snapshot سبک از DOM و قرارداد API قبل/بعد یکسان باشد؛ بازی‌ها و مسیرهای قبلی همچنان باز شوند.

## بسته C — محدودهٔ امن Studio و نشست واحد

**هدف:** رفع بازشدن فایل/Workspace اشتباه و خطای مدیر در Agent.

- یک منبع Session برای برنامهٔ 8080 و درخواست‌های Theia ایجاد شود.
- Studio عادی فقط Workspace پروژه و نسخهٔ انتخاب‌شده را ببیند.
- با تغییر بازی/نسخه، تب‌ها و فایل‌های Workspace قبلی پاک‌سازی شوند.
- «باز کردن استادیو آزاد» جدا از Studio بازی باشد و هشدار محدودهٔ آزاد داشته باشد.
- بازگشت/بستن Studio به داشبورد ویرایش انجام شود.

**معیار عبور:** بازکردن دو نسخهٔ متفاوت پشت سر هم هیچ فایل یا تب قبلی را نشان ندهد؛ مدیر بتواند از Agent پیام بفرستد.

## بسته D — Shell اصلی Theia

**هدف:** فقط اجزای Native Theia باقی بمانند.

- منوی File طبق Backlog محدود شود.
- کنترل نسخه و Preview در نوار بالای سمت راست قرار گیرد.
- پنل چت فقط یک ViewContainer Native در ستون راست و زیر Outline باشد.
- کنترل‌های چیدمان پنل‌ها مطابق تصویر مرجع، با tooltip و میانبر قابل‌فهم ساخته شوند.
- تم فقط با Preferenceهای `Dark Modern` و `Light Modern` Theia تغییر کند.

**معیار عبور:** هیچ `position: fixed` یا Overlay Agent در HTML استاتیک نباشد؛ تم روی Explorer، Editor، Problems، Terminal و Chat یکسان اعمال شود.

## بسته E — متادیتای گرافیکی و نسخه‌ها

**هدف:** متادیتا منبع واحد حقیقت باشد.

- صفحهٔ گرافیکی برای `game.json` و `README.md` داخل Editor Area ساخته شود.
- نبودن/خرابی فایل‌ها تشخیص داده شود؛ ایجاد و «تصحیح قالب» دادهٔ معتبر را حفظ کند.
- تغییر نسخه، نام پوشه، `game.json.version` و کنترل بالا را اتمی همگام کند.
- README از متادیتا تولید و در جزئیات عمومی بازی نمایش داده شود.

**معیار عبور:** تغییر فرم متادیتا هم‌زمان در کارت عمومی، کارت مدیریت، جزئیات و نسخهٔ انتخاب‌شده دیده شود.

## بسته F — Language Support و Problems

**هدف:** تجربهٔ ویرایش نزدیک VS Code Web.

- Monaco Language Support برای HTML/CSS/JS/JSON/Markdown فعال شود.
- Diagnostics، underline قرمز، Hover و Problems خط‌به‌خط اضافه شود.
- کلیک روی Problem، فایل و خط مربوط را باز کند.
- فایل‌های خالی/بلند، Word Wrap و preview رسانه‌ای پایدار شوند.

**معیار عبور:** یک خطای واقعی در HTML، CSS، JS و JSON با پیام مناسب و مکان صحیح نشان داده شود.

## بسته G — Agent اصلاح‌گر با تأیید

**هدف:** AI داخل Studio و امن باشد.

- Composer شامل مدل رایگان، فایل/تصویر، Skill و ذخیرهٔ گفتگو باشد.
- دکمهٔ «تصحیح همین اشکال» کنار Problem و خط قرمز ظاهر شود.
- Prompt پنهان، خروجی فقط-کد معتبر همان فایل را الزام کند.
- پاسخ در Diff نمایش داده شود، Snapshot ساخته شود و Apply فقط پس از تأیید اجرا شود.

**معیار عبور:** AI هرگز `game.json`/`README.md` را بازنویسی نکند، کد غیرمرتبط ننویسد و اعمال بدون تأیید ممکن نباشد.

## بسته H — یکپارچگی عمومی و امکانات بعدی

- حساب/مهمان/مدیر و پروفایل سراسری.
- امتیاز، علاقه‌مندی، نظر، پاسخ مدیر و فعالیت هفتگی واقعی.
- موبایل، PWA، Backup/Restore، Export، Git، بررسی لینک و خروجی نصب.

## ترتیب شروع

اکنون فقط **بسته A** شروع می‌شود. پس از تأیید قراردادها، **بسته B** اجرا می‌شود. از بسته C به بعد، هر بسته یک بازبینی کوتاه ظاهری و رفتاری دارد تا آشفتگی دوباره ایجاد نشود.
