# راهنمای ساده FlowForge در لینوکس

این راهنما برای اجرای شخصی روی یک کامپیوتر لینوکسی است. مراحل «اولین‌بار» فقط یک بار انجام می‌شوند؛ استفاده روزانه اینترنت لازم ندارد.

> تا وقتی اینترنت محدود دارید، فرمان‌های بخش اولین‌بار را اجرا نکنید. همه دانلودها در همان بخش هستند.

## چیزهایی که فقط یک بار لازم‌اند

به Node.js نسخه 20 یا جدیدتر و PostgreSQL نسخه 14 یا جدیدتر نیاز دارید. روی Ubuntu یا Debian، Terminal را باز و این فرمان را اجرا کنید:

```bash
sudo apt update
sudo apt install -y postgresql postgresql-client nodejs npm
```

اگر نسخه Node.js کمتر از 20 بود، نسخه LTS جدید را از سایت رسمی Node.js نصب کنید؛ سپس به ادامه مراحل برگردید.

## اولین‌بار: آماده‌سازی

### ۱. رفتن به پوشه پروژه

Terminal را باز کنید، وارد پوشه پروژه شوید. اگر پروژه در Downloads است، این نمونه را با نام پوشه خودتان اجرا کنید:

```bash
cd "$HOME/Downloads/بازی منیجر/games/F-n8n1-automation-platform"
```

### ۲. ساخت محل نگهداری اطلاعات

این فرمان PostgreSQL را باز می‌کند:

```bash
sudo -u postgres psql
```

دو خط زیر را یکی‌یکی paste و Enter کنید. عبارت `یک-رمز-قوی` را با رمز شخصی خودتان عوض کنید:

```sql
CREATE USER flowforge WITH PASSWORD 'یک-رمز-قوی';
CREATE DATABASE flowforge OWNER flowforge;
```

وقتی پیام `CREATE ROLE` و `CREATE DATABASE` را دیدید، این را بزنید و Enter کنید:

```sql
\q
```

### ۳. تنظیم فایل خصوصی

در همان پوشه پروژه این دو فرمان را اجرا کنید:

```bash
cp .env.example .env
nano .env
```

در صفحه بازشده این مقدارها را پیدا و کامل کنید:

```dotenv
APP_URL=http://localhost:3000
DATABASE_URL=postgresql://flowforge:یک-رمز-قوی@127.0.0.1:5432/flowforge
ENCRYPTION_KEY=یک-متن-تصادفی-بلند-حداقل-۳۲-کاراکتری
```

- رمز DATABASE_URL باید همان رمزی باشد که در مرحله قبل انتخاب کردید.
- ENCRYPTION_KEY باید یک متن بلند و خصوصی باشد؛ بعداً آن را تغییر ندهید.
- برای استفاده از AI، بعداً `CODEX_ACCESS_TOKEN` و در صورت نیاز `CODEX_ACCOUNT_ID` را در همین فایل وارد کنید.

برای ذخیره در nano: `Ctrl+O`، سپس Enter، سپس `Ctrl+X` را بزنید. فایل `.env` خصوصی است و نباید برای دیگران ارسال شود.

### ۴. نصب یک‌باره برنامه

در پوشه پروژه اجرا کنید:

```bash
chmod +x scripts/*.sh
./scripts/install-local.sh
```

این مرحله بسته‌های برنامه را دانلود می‌کند، دیتابیس را آماده می‌کند و برنامه را بررسی می‌کند. اگر اینترنت قطع شد، بعداً دوباره همین فرمان را اجرا کنید.

## استفاده روزانه

در Terminal وارد پوشه پروژه شوید و اجرا کنید:

```bash
./scripts/start-local.sh
```

وقتی برنامه آماده شد، مرورگر را باز کنید و به http://localhost:3000/login بروید. بار اول «راه‌اندازی اولیه» را بزنید و حساب مدیر خودتان را بسازید.

Terminal باید باز بماند تا برنامه روشن باشد. برای خاموش‌کردن، در همان Terminal کلیدهای `Ctrl+C` را بزنید.

## ساخت اتوماسیون با AI

پس از ورود، «جریان‌های کاری» و سپس «ساخت با AI» را باز کنید و خواسته را معمولی بنویسید. اگر AI نود جدید پیشنهاد داد، کد و پارامترهای آن را بررسی کنید. فقط مدیر می‌تواند نصب را تأیید کند و اجرای کد نود sandbox امنیتی نیست؛ کد ناشناس را نصب نکنید.

## مشکل‌های رایج

- **صفحه باز نمی‌شود:** Terminal را باز نگه دارید و آدرس `http://localhost:3000` را امتحان کنید.
- **خطای دیتابیس:** بررسی کنید PostgreSQL روشن است: `sudo systemctl start postgresql`.
- **AI کار نمی‌کند:** توکن `CODEX_ACCESS_TOKEN` در `.env` را وارد کنید و برنامه را یک‌بار خاموش و روشن کنید.
- **فقط می‌خواهید ظاهر را ببینید:** فایل `visual-preview.html` را در پوشه اصلی پروژه با مرورگر باز کنید؛ نمونه مستقل است و به AI یا دیتابیس وصل نیست.

## نسخه پشتیبان

پیش از تغییرهای بزرگ یک نسخه پشتیبان بگیرید:

```bash
mkdir -p backups
source .env
pg_dump "$DATABASE_URL" --format=custom --file="backups/flowforge-$(date +%Y%m%d-%H%M%S).dump"
```

فایل‌های پوشه `backups` و فایل `.env` را در جای امن نگه دارید.
