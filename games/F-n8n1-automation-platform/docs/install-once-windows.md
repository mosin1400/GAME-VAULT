# راهنمای ساده FlowForge در ویندوز

این راهنما برای کسی است که فنی نیست. فقط مرحله‌ها را به‌ترتیب انجام دهید. برنامه فقط روی همین کامپیوتر اجرا می‌شود و با مرورگر باز می‌شود.

> فعلاً چیزی نصب نکنید اگر اینترنت محدود دارید. فقط بخش «اولین‌بار» دانلود دارد؛ بخش «استفاده روزانه» اینترنت نمی‌خواهد.

## چیزهایی که فقط یک بار لازم‌اند

1. **Node.js نسخه 20 یا جدیدتر** را از سایت رسمی Node.js نصب کنید. نسخه LTS را انتخاب و تنظیمات پیش‌فرض را نگه دارید.
2. **PostgreSQL نسخه 14 یا جدیدتر** را نصب کنید. در زمان نصب رمزی برای کاربر `postgres` می‌پرسد؛ آن را در جای امن نگه دارید. بقیه گزینه‌ها همان پیش‌فرض باشند.
3. پوشه پروژه را باز کنید: `games\F-n8n1-automation-platform`.

## اولین‌بار: آماده‌سازی

### ۱. ساخت محل نگهداری اطلاعات

از Start ویندوز، **SQL Shell (psql)** را باز کنید. برای چهار سؤال اول Enter بزنید. وقتی رمز خواست، رمز انتخاب‌شده در نصب PostgreSQL را وارد کنید.

دو خط زیر را یکی‌یکی paste و Enter کنید. عبارت `یک-رمز-قوی` را با یک رمز شخصی جایگزین کنید و نگه دارید:

```sql
CREATE USER flowforge WITH PASSWORD 'یک-رمز-قوی';
CREATE DATABASE flowforge OWNER flowforge;
```

بعد از پیام‌های `CREATE ROLE` و `CREATE DATABASE`، پنجره را ببندید.

### ۲. تنظیم فایل خصوصی

در پوشه پروژه، از `.env.example` یک کپی بسازید و نام کپی را دقیقاً `.env` بگذارید؛ دقت کنید `.env.txt` نشود. فایل `.env` را با Notepad باز کنید و این سه خط را کامل کنید:

```dotenv
APP_URL=http://localhost:3000
DATABASE_URL=postgresql://flowforge:یک-رمز-قوی@127.0.0.1:5432/flowforge
ENCRYPTION_KEY=یک-متن-تصادفی-بلند-حداقل-۳۲-کاراکتری
```

- در DATABASE_URL همان رمزی را بگذارید که برای `flowforge` انتخاب کردید.
- ENCRYPTION_KEY باید خصوصی و بلند باشد؛ بعداً آن را تغییر ندهید، وگرنه رمزهای ذخیره‌شده خوانده نمی‌شوند.
- برای AI، بعداً `CODEX_ACCESS_TOKEN` و در صورت نیاز `CODEX_ACCOUNT_ID` را در همین فایل وارد کنید. بدون آن‌ها برنامه باز می‌شود، اما AI کار نمی‌کند.

فایل را Save کنید. این فایل خصوصی است؛ برای کسی ارسالش نکنید.

### ۳. نصب یک‌باره برنامه

در فضای خالی پنجره پوشه پروژه راست‌کلیک کنید و **Open in Terminal** را بزنید، سپس اجرا کنید:

```powershell
npm.cmd install
```

این تنها فرمان دانلود بسته‌های برنامه است. اگر اینترنت قطع شد، بعداً فقط همین فرمان را دوباره اجرا کنید.

### ۴. آماده‌کردن و بررسی

در همان پنجره این فرمان‌ها را یکی‌یکی اجرا کنید:

```powershell
npx.cmd --no-install drizzle-kit push --force
npm.cmd run typecheck
npm.cmd run lint
npm.cmd run build
```

فرمان اول جدول‌های برنامه را می‌سازد. اگر از قبل داده واقعی دارید، قبلش backup بگیرید. سه فرمان بعدی فقط بررسی و ساخت نسخه اجراشدنی هستند.

## استفاده روزانه

1. مطمئن شوید PostgreSQL روشن است؛ معمولاً پس از روشن شدن ویندوز خودکار اجرا می‌شود.
2. در پوشه پروژه **Open in Terminal** را بزنید.
3. این فرمان را اجرا کنید:

```powershell
.\scripts\start-local.ps1
```

4. مرورگر را باز و به http://localhost:3000/login بروید.
5. بار اول «راه‌اندازی اولیه» را بزنید و حساب مدیر خودتان را بسازید.

تا وقتی Terminal باز است برنامه روشن است. برای خاموش‌کردن، در همان پنجره `Ctrl + C` را بزنید.

## ساخت اتوماسیون با AI

بعد از ورود، «جریان‌های کاری» و «ساخت با AI» را باز کنید و خواسته را معمولی بنویسید؛ مثلاً: «هر روز ساعت ۹ یک آدرس API را بخوان و نتیجه را ایمیل کن.» اگر AI نود جدید پیشنهاد داد، کد و پارامترهایش را بررسی کنید. فقط مدیر می‌تواند نصب را تأیید کند و اجرای کد نود sandbox امنیتی نیست؛ کد ناشناس را تأیید نکنید.

## مشکل‌های رایج

- **صفحه باز نمی‌شود:** Terminal را باز نگه دارید و http://localhost:3000 را امتحان کنید.
- **خطای دیتابیس:** PostgreSQL را بررسی کنید و مطمئن شوید رمز `.env` درست است.
- **AI جواب نمی‌دهد:** `CODEX_ACCESS_TOKEN` در `.env` را وارد کنید، سپس برنامه را یک‌بار خاموش و روشن کنید.
- **فقط می‌خواهید ظاهر را ببینید:** `visual-preview.html` در پوشه اصلی پروژه را دوبار کلیک کنید. این فقط نمونه نمایشی است، نه اتصال واقعی AI یا دیتابیس.

## نگهداری امن

برای نسخه پشتیبان از اطلاعات، در Terminal اجرا کنید:

```powershell
.\scripts\backup-local.ps1
```

فایل backup در پوشه `backups` ساخته می‌شود. فایل `.env` و پوشه `backups` را در جای امن نگه دارید.
